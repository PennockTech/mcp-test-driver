mcp-test-driver

An interactive REPL and diagnostic tool for testing Model Context Protocol servers. Source, documentation and releases: github.com/PennockTech/mcp-test-driver.

This site exists to host the tool's OAuth Client ID Metadata Document, which authorization servers fetch when mcp-test-driver logs in to an MCP server.

Install from PyPI, or run it without installing: uvx mcp-test-driver <server command or URL>.
